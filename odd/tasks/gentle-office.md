# Gentle Office
Pixel-art office (Gentleman-Cute palette, 32-bit style) that visualizes real gentle-shell activity, shipped as its own Pi package from this repo.
Design source: design/agent-office/ (01 overworld HQ, 02 dock pane, 03 story mode). Built step by step to avoid refactors.

## Specs
- S1 — Real agents drive the scene: "Va vinculado a un agente trabajando". Each character maps to a real session/subagent; filler animations (coffee, walking) only fill gaps between real events.
- S2 — Toggle the module: "como activar o desactivar este modulo". Off by default; `agent/gentle-office.json` `{ "enabled": false }` plus an `/office` command; when off, no listeners or server run.
- S3 — Display surfaces: "(Cambiaria el texto que ahroa tenemos por esta animacion)?O tener en una ventana por separado". First a separate localhost browser window (loopback only, token URL, like the gentle-design canvas); later an optional small TUI widget that replaces the working label.
- S4 — Step order: "vamos por pasos, la zona, y luego personage a personage" / "paso a paso para evitar un refactoring". Event contract first, then the zone + orchestrator + coffee pot, then one character type per task.
- S5 — Coffee pot = tokens: "QUe los tokens consumidos sea una jarrita de cafe que se va agotando mientras toman cafe." Pot level = 1 - context usage percent; compaction = brewing a fresh pot.
- S6 — Orchestrator look and behavior: "el orchestrador en la pisarra cuando esta haciendo algo y si no caminando" and "Al orchestrador un bigote mustache rosa,grandey unas gafas monocular."
- S7 — Reviewers and judges: "Cuando hay que llamar los revisores, estaria guay que entraran 2 personages, con maletines, y lupa. Como inspectores. que cada agente se parezca a su roll, y jueces que se ponga los 2 judges a debatir entre ellos."
- S8 — Represent gentle-shell features: "Mira todas las funcionalidades de Gentle-shell para intentar representar en la escena, como gentle-stream, musica. Gentle-design(no se como podria se representar.)etc"
- S10 — Bigger characters: "que los personagens sea un poco mas grandes, para que se vea detalles". Decision: larger sprites in the same room (not a whole-scene zoom).
- S11 — Command selector: "que el comando no tenga que escribir /office on , off, open que me abra un selector."
- S12 — Decisions as a game dialog: "Que las decisiones me aparezcan asi con un cuadro de textos como en los videojuegos" (reference: design/agent-office/03-story-mode.html dialog box). Decision (L19): for now only show the question and its options in a dialog; answering from the window is deferred.
- S13 — Compact layout option: "tenias una opcion de design mas compacta agregamos como opcion? dock panel creo." (design/agent-office/02-dock-pane.html).
- S14 — Story mode layout: "El compact se ve todo muy pequeno podria tenermo un story mode? como me presentaste ne la primera idea de design? El story mode tambien quedaria interesante esta opcion en full" (design/agent-office/03-story-mode.html: close-up camera following the last agent that acted, HP-style brew bar, party panel, Pokémon dialog narrating each event). Also: "falta el chat que habia antes tambien con lo que haces y esta haciendo cada agente. el dialogo."
- S15 — Terminal office: "como podriamos hacer esto en la terminal, uso ghostty, podrias hacer un design para ver visualmente como quedaria, sustituiendo la parte central por el escenario, el ocestrator no haria falta que estuviera moviendo todo el rato para ahorrar recursos."
- S16 — Idle crew on view: "Como tenemos web y estamos desenvolviendo la del terminal, podriamos dejar a la vista los otros agentes si no estan trabajanmdo, que esten charlando o tomando cafe." Decision: one idle staff member per role (explore, worker, verify) hangs out by the coffee machine / lounge chatting or sipping coffee; when a real subagent of that role starts, that staff member walks to a desk and becomes it; extra agents of the same role still walk in from the door; when it finishes it walks back to the lounge instead of leaving. Applies to web (all layouts) and the terminal designs.
- S17 — Tidy floor plan: "nom me gusta qu este los 3 en linea pegado, se hace raro. podemos mejorar esta escena esta muy cargada, los muebles todos tirados, podemos dejar una salita para el orchestrator, las mesas como son 4 una frente otra con separador en cruz, como las ofinas, en el lado izquierdo una mesa con los 2 jueces en un lateral , y en otra esquina los verify con su pantalla de invesigacion y su mesa. La radio , el cabalete, archivador.. hay que redistribuir. parece una oficina desordenada jajaja"
- S9 — Boss = the user, playable: "poder usar gentle-shell practicamente como se fuera un juego. Agregar el boss, como Yo el usuario. Dueno de la empresa con traje y corbata. Ahi me puedo mover yo libremente en el Office.. El input lo puedo ir a un ordenado, y escribir ahi por ejempo o precionando una tecla". The window gets an inbound input channel (boss prompt → orchestrator session); it must be authenticated (session token), loopback-only and Origin-checked.
